The module is a Playwright Test suite (`.spec.mjs` files) driven by a shared `launch.mjs` helper. `launch.mjs` uses `@playwright/test`'s `_electron` launcher to start the real Electron process (`electron.launch`) with a fresh temp directory under `tmpdir()` for `settings.json`, downloads, and E2E state; it injects deterministic defaults (`onboardingComplete: true`, `offlineOnly: true`, `animateMascot: false`, etc.), sets `TZ=UTC`/`LANG=C.UTF-8`, and waits for `[data-ready="yes"]` before returning `{app, page, dir}`. A second helper `go(page, view)` navigates via the injected `window.__surfNav` bridge. Each spec file imports `launch` (and optionally `go`), wraps its test body in `try/finally` to close the app and `rmSync(dir, { recursive: true })`, and drives assertions against DOM attributes like `[data-screen]`, `[data-sync-state]`, `[data-theme-row]`, `[data-composer]`, etc. The `visual.spec.mjs` file pairs these assertions with `toHaveScreenshot(...)` against baseline PNGs under `snapshots/`, using `mask` and per-test viewport overrides to stabilize diffs. `model-reply.spec.mjs` is an optional integration test gated on `SURF_MODELS_DIR` and given a 6-minute timeout to stream a Qwen 2B reply. `smoke.spec.mjs` exercises the activation lock, chat/settings/usage screens, network mode switching, and demo data injection via `window.__surfDemo('versions')` / `window.__surfDemo(scene)`.
