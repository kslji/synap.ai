The app follows the standard Electron three-process layout: `src/main/` runs the Node/Electron main process (sidecar manager, model registry, SQLite indexing, code-agent loop, IPC handlers); `src/renderer/` is a Vite-built React SPA; `src/preload/` exposes a sandboxed `window.surf` API. Cross-process communication goes through the typed IPC contract defined in `src/shared/ipc-contract.ts` (mirrored by `src/main/core/ipc-contract.ts`) plus JSON Schema payloads in `ipc-schemas.ts`, so both sides share one source of truth for message shapes. The renderer never talks to the OS directly — all file access, sidecar invocation, and native features flow through the preload bridge. Build-time assets (llama.cpp sidecars, whisper CLI, tree-sitter WASM grammars, tessdata OCR models) are downloaded and staged under `resources/` by scripts in `scripts/`, then packaged via electron-builder (`electron-builder.cjs`). E2E tests in `e2e/` launch the built app with Playwright against the same IPC surface used by the renderer.
