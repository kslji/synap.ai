FastAPI + Pydantic v2 on Python 3.12, async Postgres via `psycopg_pool` (with pgvector extension), Valkey/Redis for distributed rate limiting and search cache, Alembic for migrations, JWT HS256 access tokens (audience `authenticated`, `typ` `access`, `sub` = device id), httpx for upstream calls to SearXNG and external pages, Stripe/Razorpay webhook verification, Ed25519 signing for packs and model registry.
