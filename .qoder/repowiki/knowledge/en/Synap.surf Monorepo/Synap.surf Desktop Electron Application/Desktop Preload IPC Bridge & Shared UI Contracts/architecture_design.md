Two cooperating sub-trees with one-way dependency: `preload/index.ts` is the only Electron preload entry — it imports `contextBridge`, wraps every `ipcRenderer.invoke`/`on` call behind a typed `SurfApi` object grouped by domain (chat, models, setup, packs, auth, licence, settings, updates, conversations, webCache, usage, storage, library, links, codeAgent, devWeb, documents, code, codeComplete, codeVision, files, speech), and exposes it via `contextBridge.exposeInMainWorld('surf', api)`. The `shared/` directory holds no runtime dependencies on Electron; it is consumed by both main and renderer. `shared/ipc-contract.ts` is the single source of truth for IPC channel names (`IPC` const map using `domain:action` strings) and all request/response/event types (e.g. `ChatEvent`, `ModelStatus`, `SetupSnapshot`, `SurfApi`). Other `shared/*.ts` files are pure utilities (chat-title, cited-sources, stream-batching, model-label, hardware-label, offline-pack, quote, reply-text, setup-link, starter-model, surf-chip, completion-edit, code-ram, model-output) each paired with a co-located `*.test.ts`. Dependency direction: preload → shared/ipc-contract; shared modules have no cross-dependencies beyond `setup-choice` re-exporting `SetupSnapshot`.
