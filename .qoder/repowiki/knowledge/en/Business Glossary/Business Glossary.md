### Knowledge Pack
- Definition：A signed, versioned bundle of curated sources (documents, code, etc.) that the desktop app can install to extend its domain knowledge. Packs are distributed via the pack catalog, auto-update every 24 hours when online, work offline after installation, and support USB transfer between machines.
- Aliases：pack、knowledge pack

### Niche Agent
- Definition：A data-driven agent profile defined by a signed manifest (prompt, tools, rules) paired with one or more knowledge packs. No new code is needed to add a vertical; the Marine Engineer was the first niche, with Construction, Aviation, Doctor, and Finance planned.
- Aliases：agent、niche

### Hardware Tier
- Definition：The RAM-based classification (tier0 < 8 GB, tier1 = 8 GB, tier2 = 16 GB, tier3 = 32 GB+) that selects the local model size (Qwen3.5-2B/4B/9B), embedding model, and token budget profile. It drives whether the server-side context window is 8K or 16K.
- Aliases：tier、hw.tier

### SYNAP key
- Definition：A human-readable licence key format accepted by the activation flow: prefix `SYNAP-` followed by four groups of four characters drawn from `ABCDEFGHJKLMNPQRSTUVWXYZ2-9`. Normalization strips spaces and hyphens before hashing.
- Aliases：licence key、activation key

### Lite mode
- Definition：Development/server mode where the API runs without Postgres/Valkey, using in-memory stores for auth, licences, rate limiting, and search caching. Enabled by setting `SURF_API_LITE=1` or omitting `DATABASE_URL`.
- Aliases：lite

### Dev open
- Definition：A development-only bypass flag (`SURF_DEV_OPEN=1`) that skips sign-in and daily search quota on the API. Only valid in lite mode and explicitly rejected on public hosts.
- Aliases：dev_open、SURF_DEV_OPEN

### Offline only
- Definition：The user-facing switch in Settings that disables the optional cloud-dependent features (web search, page fetch, pack updates). When off, the app reaches out to the Surf API; when on, everything runs locally.
- Aliases：offline switch

### Pack delta
- Definition：An incremental update payload for a knowledge pack, built by `services/packs/build_delta.py`, allowing the client to apply changes instead of re-downloading the full bundle.
- Aliases：delta、pack delta

### Code pack
- Definition：A special kind of pack containing source code cards (generated by `scripts/code-pack-src/`) that the desktop's code agent can index and reason about. Built and signed separately from document packs.
- Aliases：code-pack

### Sidecar
- Definition：The external llama.cpp process that runs alongside the Electron app and handles model inference; the main process communicates with it over a local IPC channel.
- Aliases：model sidecar
