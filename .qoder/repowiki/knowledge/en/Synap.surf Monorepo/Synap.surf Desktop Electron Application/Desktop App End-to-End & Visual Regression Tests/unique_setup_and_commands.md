Tests require a built Surf desktop app at `apps/desktop/` (the launcher's `cwd`). Microphone-related tests pass Chromium flags `--use-fake-device-for-media-stream --use-fake-ui-for-media-stream` and/or set `SURF_E2E_MIC_TEXT` / `SURF_E2E_MIC=denied` to simulate mic input or denied permissions.
