Evaluation harness requires Node 22 and llama-server sidecar: `python3 -m pip install -r harness/requirements.txt`, then `cd apps/desktop && node scripts/fetch-sidecars.mjs && cd ../..`, export `SURF_MODELS_DIR="$HOME/surf-models"`, and run `npm run eval` (or `./harness/run.sh quick/full`). Baselines are written via `python3 harness/core/run_eval.py --mode quick --write-baseline` and committed under `harness/baselines/quick.json`.
