Two sibling trees with a clear dependency direction: `scripts/` are executable Node/Python tooling; `resources/` are the generated artifacts they write into.

- Download layer: `http-download.mjs` provides a shared `undici` Agent with long connect/body timeouts plus `withDownloadRetry` exponential-backoff retry. All fetch scripts (`fetch-sidecars.mjs`, `fetch-whisper.mjs`, `fetch-tree-sitter.mjs`, `fetch-dbip-country.mjs`, `fetch-tessdata.mjs`, `model-weights.mjs`) import this module rather than calling `fetch` directly.
- Binary staging: `fetch-sidecars.mjs` resolves a pinned ggml-org/llama.cpp release asset per `<platform>-<arch>` (+ optional `--gpu=cuda|vulkan`) and writes it to `resources/bin/<platform>-<arch>/`; `extractArchive` is reused by `fetch-whisper.mjs`. Whisper additionally builds from source on macOS via cmake when no prebuilt archive exists.
- Grammar/model assets: `fetch-tree-sitter.mjs` pulls npm-packaged `.wasm` grammars into `resources/tree-sitter/`; `fetch-whisper.mjs` stages `whisper-cli` + shared libs into `resources/whisper/<platform>-<arch>/`.
- Packaging: `pack-offline-zip.ts` assembles an offline zip containing the built app plus one Qwen model + embedding, signs the Mac bundle with ad-hoc `codesign`, zips with `zip -0` (store), and uploads to GitHub Releases or Hugging Face datasets depending on size and `HF_TOKEN`.
- Electron integration: `after-pack.cjs` is an electron-builder hook that ad-hoc signs the `.app` on darwin when `CSC_LINK` is unset.
- Utilities: `rss.ts` reads RSS from `/proc` (Linux) or `ps` (other platforms); `render-icons.py` generates icon assets; `bench-completion.ts`, `measure-code-index.ts`, `measure-ram.ts`, `model-eval.ts`, `code-pack-eval.ts`, `code-pack-shots.ts`, `shot-file-search.mjs`, `check-budget.mjs`, `coverage.mjs` are measurement/benchmark helpers.
- Static resources under `resources/`: `bin/darwin-arm64/` ships the staged llama.cpp binaries and native dylibs; `tree-sitter/*.wasm` are the grammar files consumed at runtime; `tessdata/` holds Tesseract trained data; `models.registry.json`, `pack-keys.json`, `release-mode.json`, `icon.png`, `licence-public.json`, `code-pack/manifest.*` are metadata consumed by the app and packaging pipeline.
