The module is a standard Electron renderer React app rooted at `index.html` → `src/main.tsx`, which mounts `<App />` inside `MascotColorProvider` and `MascotActivityProvider` from `@surf/ui`. `App.tsx` is the single orchestrator: it owns global state (`status`, `settings`, `conversations`, `messages`, `files`, `packs`, `licence`, `setupLive`, `updateOffer`, `tourStep`, `convertJob`, `fillJob`) and dispatches between screens via a string-typed `View` union in `types.ts`. Screens live under `src/screens/` as sibling React components; `App` imports them directly rather than using a router. Cross-cutting concerns are isolated in top-level files: `mascot-activity.tsx` exposes a context-driven mascot mood/state, `tour.ts` declares the guided tour steps, `format.ts` and `file-gallery.tsx` provide shared helpers, and `model-site.ts` hosts model metadata. The IPC boundary is typed by importing `ChatEvent`, `CodePlanView`, `StoredMessage`, etc. from `../../shared/ipc-contract`; event streams from `api.chat.onEvent`, `api.library.onEvent`, `api.code.onEvent`, `api.documents.onEvent`, `api.models.onEvent` are consumed in `App` and reduced into local state via `applyEvent` in `types.ts`. A `window.__surfDemo` / `window.__surfNav` / `window.__surfTheme` bridge lets the main process drive demo scenes and navigation. The `public/theme-boot.js` script runs before React to set CSS variables based on persisted theme.
