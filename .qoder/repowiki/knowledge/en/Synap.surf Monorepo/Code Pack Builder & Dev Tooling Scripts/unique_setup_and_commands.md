`scripts/build-code-pack` requires either `CODE_PACK_SIGNING_KEY` (64-hex seed) plus `CODE_PACK_SIGNING_KEY_ID` pointing to a public key in `apps/desktop/resources/pack-keys.json`, or `--dev-key --update-dev-pubkey` which writes a local `.dev-seed` (mode 0600, gitignored). Production builds are run by `.github/workflows/code-pack.yml`; PR CI verifies the committed pack instead of re-signing because forks lack the secret.
