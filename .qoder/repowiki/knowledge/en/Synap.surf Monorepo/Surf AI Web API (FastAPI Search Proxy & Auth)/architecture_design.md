Single-process FastAPI app (`app/main.py`) with a `lifespan` manager that wires runtime state (`app.state.pg`, `app.state.kv`, `app.state.auth`, `app.state.licences`, `app.state.limiter`, `app.state.mail`, `app.state.http`). Two operational modes are selected at startup: `SURF_API_LITE=1` (or missing `DATABASE_URL`) uses in-memory stores (`MemoryAuth`, `MemoryLicences`, `MemoryLimiter`, process-local cache) for local dev; production connects to Postgres via `psycopg_pool.AsyncConnectionPool` and Valkey via `redis.asyncio`. Route handlers live in `main.py`; domain logic is split into sibling modules — `auth_store.py`/`tokens.py` for OTP/JWT auth, `licences.py`/`licence_store.py` for licence lifecycle and Stripe/Razorpay webhooks, `limiter.py` for per-device rate/quota limits, `pack_catalog.py` for signed pack manifests, `pages.py` + `ssrf.py` for the `/v1/fetch` proxy, `content_key.py` for Ed25519-sealed content keys, `injection.py` + `injection_rules.json` for prompt-injection scoring, `mailer.py` for SMTP/console mail delivery, and `sanitize.py` for HTML sanitization. Alembic migrations under `alembic/versions/` manage Postgres schema; `models.registry.json` is served as a signed model catalogue. The Dockerfile runs uvicorn with 2 workers behind Caddy in production.
