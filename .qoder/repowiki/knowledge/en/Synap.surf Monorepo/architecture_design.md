The repo is an npm workspaces monorepo (`package.json` `workspaces`) that owns the Node/Electron/React side: `apps/desktop` (Electron main + React renderer), `apps/web` (Vite marketing SPA), `packages/ui` (React primitives + theme), and `packages/shared` (product constants / agent manifest types). Python services live outside the workspace graph: `services/api` (FastAPI search proxy + auth + signed pack catalog) and `apps/host` (legacy OTP platform reused for rate-limit policy). Cross-cutting concerns are centralized at the root: `deploy/docker-compose*.yml` boots the production stack (Caddy, API, Postgres/pgvector, Valkey, SearXNG); `harness/run.sh` drives the eval harness against host + desktop; `scripts/check.sh` runs lint/typecheck across workspaces; `agents_catalog/` provides the declarative agent manifests consumed by both the desktop and the pack builder. The desktop app is the primary client — it calls `services/api` over HTTP (default `http://127.0.0.1:8000`, overridden by `SYNAP_API_URL`) and consumes `@surf/shared` + `@surf/ui` via workspace links.
