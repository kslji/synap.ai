Local lite mode: `python3 -m pip install -r requirements.txt && SURF_API_LITE=1 SURF_DEV_OPEN=1 SEARXNG_URL=http://127.0.0.1:8080/search JWT_SECRET=dev-only-secret-change-me-at-least-32-bytes python3 -m uvicorn app.main:app --app-dir . --host 127.0.0.1 --port 8000`. Tests: `python3 -m pip install -r requirements-dev.txt && python3 -m pytest`. Migrations: `alembic upgrade head` against `DATABASE_URL` (Alembic auto-prefixes `postgresql://` with `+psycopg`). Production compose stack lives in repo root `deploy/docker-compose.dev.yml` and sets `SURF_DEV_OPEN=1`.
