- `packages/shared` is a pure TypeScript library (`@surf/shared`) with no runtime dependencies. It exports immutable product constants (`product`, `modelTiers`, `embeddingModel`) from `src/index.ts` and domain primitives for agents (`AgentMeta`, `AgentStatus`, `parseAgentFile`, `sortAgents`, `agentCanOpen`, `agentCanChat`) from `src/agents.ts`. A `PackManifestShape` interface defines the surf/harbor pack contract. Built via `tsc -p tsconfig.json`; source files are re-exported directly through `exports.import` so consumers get TS types without a separate build step.
- `packages/ui` is a React 19 library (`@surf/ui`) declared as a peer dependency of consumers. Its barrel `src/index.ts` re-exports: Markdown parser/renderer (`markdown.tsx`), the animated SVG blob mascot (`blob.ts`, `BlobMascot.tsx`, `mascot.ts`, `mascot-color.tsx`), parallax hook (`parallax.ts`), and theme persistence (`theme.ts`, `ThemeSwitch.tsx`). CSS assets `tokens.css` and `components.css` are published as separate entry points via `package.json` `exports`.
- Dependency direction is one-way: `@surf/ui` has no dependency on `@surf/shared`; they are sibling packages consumed independently by the host app. Both use ESM (`"type": "module"`) and ship `.d.ts` alongside source via the `exports` map.
