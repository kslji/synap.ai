Single-page app bootstrapped by `src/main.tsx` which wraps `<App />` in `MascotColorProvider` and persists a PIP color via localStorage. `src/App.tsx` is the sole router: it matches literal paths (`/`, `/docs`, `/pricing`, `/features`, `/about`, `/contact`, `/privacy`, `/security`, `/contribute`, `/terms`, `/buy`) to page components and a regex route `/agents/:id` that resolves against `agents` from `@surf/shared`. Pages live in two groups: marketing content under `src/marketing/` (home, features, pricing, about, contact, docs, shell layout helpers) and legal/commerce pages under `src/pages.tsx` (PrivacyPage, SecurityPage, BuyPage, TermsPage, ContributePage plus the shared SiteHeader/SiteFooter/Page shell). Shared utilities — release metadata, download-link resolution, client OS/arch detection, form helpers, footer links — are centralized in `src/site.ts`; the blog post loader lives in `src/agent-blog.ts` using `import.meta.glob` over markdown files in `../../../agents/*/blog/*.md`. Styling uses Tailwind v4 via `@tailwindcss/vite` with CSS custom properties from `@surf/ui/tokens.css` and `components.css`, aliased through `vite.config.ts`. The app depends on sibling packages `@surf/shared` (product info, agent catalog) and `@surf/ui` (BlobMascot, ThemeSwitch, theme persistence), but has no reverse dependency.
