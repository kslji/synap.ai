`chmod +x harness/run.sh && ./harness/run.sh` — default `host` mode requires the auth host running on `127.0.0.1:18765`. `./harness/run.sh quick|full` additionally requires `python3 -m pip install -r harness/requirements.txt`, downloads models to `$HOME/surf-models` (overridable via `SURF_MODELS_DIR`), and needs a display (`DISPLAY=:1` default). Use `--write-baseline` after a passing local run to update `baselines/{mode}.json`.
