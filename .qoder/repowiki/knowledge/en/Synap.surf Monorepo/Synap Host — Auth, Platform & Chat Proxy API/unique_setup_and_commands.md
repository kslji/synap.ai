Local dev: `python3 -m venv apps/host/.venv && .venv/bin/pip install -r requirements.txt && cp ../../.env.example ../../.env && python -m uvicorn main:app --app-dir apps/host --host 127.0.0.1 --port 18765`. Production uses `gunicorn -c gunicorn.conf.py main:app` under systemd `deploy/synap-host.service` bound to `127.0.0.1:18765` with `WEB_CONCURRENCY=2` and `PLATFORM_DATA_DIR=/var/lib/synap/platform`. Checks run via `./scripts/check.sh` and integration smoke tests via `./harness/run.sh`.
