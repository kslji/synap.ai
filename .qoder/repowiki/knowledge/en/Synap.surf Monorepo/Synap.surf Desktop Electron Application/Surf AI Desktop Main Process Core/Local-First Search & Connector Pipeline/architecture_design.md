The module is a layered search pipeline with clear dependency direction: `types.ts` defines the shared `LocalHit`, `ConnectorHit`, `Intent`, and `RegionChoice` contracts; `intent.ts` classifies a question into one of six intents (`finance|legal|code|paper|news|general`) via regexes before any network call. Routing is split between `router.ts` (decides whether to stay local using `LOCAL_LAYER_ORDER` — pack/history/project/cache/files — or go online) and `run.ts` (the production entry point `composeRouted` / `gatherOnline`). Online fetching goes through `http.ts`'s `politeFetch`, which enforces HTTPS-only, blocks private/metadata IPs, applies per-host rate-limiting buckets, and attaches a `SynapSurf/0.1` user agent. Official APIs live in `connectors.ts` as individual functions keyed by `CONNECTORS` and selected by intent via `BY_INTENT`; they all return normalized `ConnectorHit[]` through a shared `hit()` factory. Fallback is DuckDuckGo lite (`ddg.ts`). Finance, legal, and news are composed inline in `run.ts` so the model never invents figures/headlines/statutes; each path funnels through `verify-answer.ts` for groundedness checks. Results are persisted in an encrypted SQLite table `search_disk_cache` (`cache.ts`) with 24h TTL for search rows and 7-day TTL for page text, evicted by oldest-first when exceeding 32 MiB. A global blocklist (`blocked.ts`) drops Reddit/X/Twitter hosts from every result set. Domain-specific helpers live in sibling files: `finance.ts`, `legal.ts`, `quotes.ts`, `reader.ts` (page scraping), `js-page.ts`, `citations.ts`, `delta.ts` (+ `delta.test.ts`), `mode.ts`, `region.ts`, `no-fabrication-suite.ts`, plus fixtures under `fixtures/`.
