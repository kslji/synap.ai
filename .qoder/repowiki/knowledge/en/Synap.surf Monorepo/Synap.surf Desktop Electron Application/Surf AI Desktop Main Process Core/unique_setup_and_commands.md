Entry mode is selected by environment variables at process start: `SMOKE` runs a minimal DB+sidecar smoke test, `SELFTEST=1` executes an end-to-end self-test suite (SQLite cipher round-trip, embedder, RAG ingestion, web citation, renderer sandbox probe) writing results to `selftest.json`, `EVAL` delegates to `eval-run.ts`, and otherwise `createServices()` boots the full app. `CAPTURE_DIR` triggers automated screenshot capture of every UI view across light/dark themes.
