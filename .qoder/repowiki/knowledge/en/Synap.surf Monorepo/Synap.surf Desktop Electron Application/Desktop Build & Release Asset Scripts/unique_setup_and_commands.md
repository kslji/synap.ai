Scripts are invoked directly with `node scripts/<name>.mjs` (or `tsx` for `.ts` helpers). Key invocations: `node scripts/fetch-sidecars.mjs [--gpu=vulkan] [--platform=darwin] [--arch=arm64]` to populate `resources/bin/<platform>-<arch>/`; `node scripts/fetch-whisper.mjs [--platform=darwin] [--arch=arm64]` (macOS requires `cmake` to build whisper-cli from source); `node scripts/pack-offline-zip.ts --app <dir> --os mac|windows --arch arm64|x64 --token 2b|4b|9b --version <ver> --out <dir> --catalog <file.json>` (requires `HF_TOKEN` env var for Hugging Face uploads and `HF_OFFLINE_REPO` for the dataset repo).
